Target outcomes

Written before opening the data. Quoted from the Results section of Experiment 2 (p. 1685):

According to a mixed analysis of variance (ANOVA) with group (Spanish vs. Moroccan) as a between-subjects factor and temporal focus (past vs. future) as a within-subjects factor, temporal focus differed significantly between Spaniards and Moroccans, as indicated by a significant interaction of temporal focus and group, F(1, 78) = 19.12, p = .001, ηp2 = .20 (Fig. 2). Moroccans showed greater agreement with past-focused statements than Spaniards did, t(78) = 4.04, p = .001, and Spaniards showed greater agreement with future-focused statements than Moroccans did, t(78) = −3.32, p = .001.

Only corrected_EH yields 80 participants × 21 items (11 PAST, 10 FUTURE), matching the paper’s N = 80 and df = 78, so it is used as the primary data. The other two versions are run as a sensitivity check.

# Per-participant mean agreement for each subscale
make_means <- function(d) {
  d |>
    group_by(group, participant, subscale) |>
    summarise(rating = mean(agree), n_items = n(), .groups = "drop") |>
    mutate(id = factor(paste(group, participant)),
           group = factor(group, levels = c("Spaniard", "Moroccan")),
           subscale = factor(subscale, levels = c("PAST", "FUTURE")))
}

run_tests <- function(m) {
  a  <- summary(aov(rating ~ group * subscale + Error(id / subscale), data = m))
  w  <- a[["Error: id:subscale"]][[1]]
  int_row <- grep("group:subscale", rownames(w))
  res_row <- grep("Residuals", rownames(w))

  tt <- map(c(PAST = "PAST", FUTURE = "FUTURE"), \(s) {
    x <- filter(m, subscale == s)
    # Moroccan minus Spaniard, matching the sign convention in the paper
    t.test(x$rating[x$group == "Moroccan"], x$rating[x$group == "Spaniard"], var.equal = TRUE)
  })

  tibble(
    F_int   = w[int_row, "F value"],
    df1     = w[int_row, "Df"],
    df2     = w[res_row, "Df"],
    p_int   = w[int_row, "Pr(>F)"],
    pes_int = w[int_row, "Sum Sq"] / (w[int_row, "Sum Sq"] + w[res_row, "Sum Sq"]),
    t_past  = tt$PAST$statistic,   df_past = tt$PAST$parameter,   p_past = tt$PAST$p.value,
    t_fut   = tt$FUTURE$statistic, df_fut  = tt$FUTURE$parameter, p_fut  = tt$FUTURE$p.value
  )
}

Summary of the reproduction (agent’s claim)

Using the fully corrected file (EHedit), all three target outcomes reproduce in direction, significance and approximate size, but not exactly:

  • Interaction: F(1, 78) = 19.15 vs. 19.12 reported; ηp² = .197 (rounds to .20, matches). Actual p ≈ 3.7 × 10⁻⁵; the paper’s “p = .001” appears to be a floor/rounding convention.
  • PAST: t(78) = 4.00 vs. 4.04 reported (p ≈ .0001).
  • FUTURE: t(78) = −3.36 vs. −3.32 reported (p ≈ .001).
  • Cell means match Fig. 2 to within ~0.01–0.02.

All discrepancies are under ~1.5% of the reported value and every df matches. The original OSF file (participant-ID error) gives the wrong df (76/77) and cannot reproduce the reported df. Welch t-tests give the same t values with non-integer df, and item-level t-tests are far off, so neither explains the small residual difference. A likely cause is that the authors’ working file differed slightly from any of the three posted versions (for example, a few response values or item–participant assignments around the mislabelled participants 24/25/40). My own classification would be minor numerical errors for all three outcomes, with the conclusions unaffected.
